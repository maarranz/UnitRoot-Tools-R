Unit-root testing with unitroottools

This vignette shows the main functions of unitroottools with one data set: the logarithm of U.S. real GDP, 1947Q1–2012Q4, used by Enders to illustrate the testing of unit roots when the deterministic terms are unknown. The data are included in the package.

library(unitroottools)

gdp <- read.csv(system.file("fixtures", "enders_rgdp.csv", package = "unitroottools"))
lgdp <- ts(log(gdp$rgdp), start = c(1947, 1), frequency = 4)
plot(lgdp, ylab = "log real GDP")

1. The augmented Dickey-Fuller test

The ADF test regression is

Δyt=a+γt+byt−1+∑j=1kβjΔyt−j+εt, \Delta y_t = a + \gamma t + b\, y_{t-1} + \sum_{j=1}^{k} \beta_j \Delta y_{t-j} + \varepsilon_t ,

and the null hypothesis of a unit root is H0:b=0H_0: b = 0 against H1:b<0H_1: b < 0. The trend argument chooses the deterministic terms: "n" (none), "c" (constant) or "ct" (constant and trend).

adf(lgdp, trend = "ct", lags = 1)
#> Augmented Dickey-Fuller test (tau3)
#> 
#>   H0: unit root
#>   H1: stationary around a linear trend
#>   Deterministics: constant and linear trend
#>   Lags: 1 (fixed)
#>   Effective sample: N = 262 (t = 3, ..., 264)
#> 
#>   Statistic:        -1.489
#>   Critical values:  1%: -3.994   5%: -3.427   10%: -3.137
#>   Source:           MacKinnon (2010) response surface
#>   p-value:          0.831
#> 
#>   Decision at 5%: do not reject H0 (unit root)

Every result states the hypotheses in words, the deterministic terms, how many lags were used and how they were chosen, the effective sample, the critical values and where they come from, the p-value, and the decision. The critical values are MacKinnon’s, computed for the actual sample size rather than read from a table; the p-value (MacKinnon, 1996) is computed for the same sample size, so the two always agree. The decision is taken from the critical value.

summary() adds the accompanying ϕ\phi statistics, with their own critical values, and the test regression:

2. Choosing the number of lags

If lags is not given, the number of lagged differences is chosen by an information criterion; the default is the modified AIC (MAIC) of Ng and Perron (2001). The candidates are k=0,…,kmaxk = 0, \dots, k_{\max}, with Schwert’s rule kmax=⌊12(T/100)1/4⌋k_{\max} = \lfloor 12 (T/100)^{1/4} \rfloor unless you give max_lags. All candidates are compared on the same observations, and the whole table is shown, not only the winner:

select_lags(lgdp, trend = "ct")

3. Which deterministic terms? Specification strategies

The ADF test depends on the deterministic terms, but we rarely know which ones belong in the regression. ur_strategy() implements three answers, and records every step.

The original procedure (Dolado, Jenkinson and Sosvilla-Rivero, as set out by Enders) starts with constant and trend and tests its way down:

ur_strategy(lgdp, "original", lags = 1)
#> Specification strategy: Original (Dolado-Jenkinson-Sosvilla-Rivero / Enders)
#> 
#>   Lags: 1 (fixed)
#>   Sample (all regressions): N = 262 (t = 3, ..., 264)   Level: 5%
#> 
#>   Step Regr.  Test       Statistic Crit.val.  p-value  Decision    Next
#>   1    ct     tau3          -1.489    -3.427    0.831  not reject  test phi3
#>   2    ct     phi3           2.966     6.340        -  not reject  go to stage C
#>   3    c      tau2          -2.049    -2.873    0.266  not reject  test phi1
#>   4    c      phi1          25.485     4.630        -  reject      test constant, b = 0 imposed
#>   5    aux_c  t(const)       6.797     1.969  < 0.001  reject      conditional t test of b
#>   6    c      t(b) cond.    -2.049    -1.651    0.021  reject      stop
#> 
#>   Specification: constant
#>   Conclusion:    no unit root: stationary around a non-zero mean
#> 
#>   Note: p-values are for each step on its own (none for the phi tables);
#>   no p-value or size is reported for the sequence as a whole.

It ends by rejecting the unit root with a conventional t test, so it concludes that log GDP is stationary around a constant mean. Enders himself calls this result nonsense: the procedure has removed the trend and then justified a t test by the presence of the constant.

The conservative variant stops when τ2\tau_2 does not reject, keeping the constant:

ur_strategy(lgdp, "conservative", lags = 1)
#> Specification strategy: Conservative
#> 
#>   Lags: 1 (fixed)
#>   Sample (all regressions): N = 262 (t = 3, ..., 264)   Level: 5%
#> 
#>   Step Regr.  Test       Statistic Crit.val.  p-value  Decision    Next
#>   1    ct     tau3          -1.489    -3.427    0.831  not reject  test phi3
#>   2    ct     phi3           2.966     6.340        -  not reject  go to stage C
#>   3    c      tau2          -2.049    -2.873    0.266  not reject  stop
#> 
#>   Specification: constant
#>   Conclusion:    unit root (constant retained)
#> 
#>   Note: p-values are for each step on its own (none for the phi tables);
#>   no p-value or size is reported for the sequence as a whole.

Hamilton’s rule does not test for the deterministic terms at all: you decide, by looking at the data and thinking about the economics, whether the series is trending. Log GDP clearly is:

ur_strategy(lgdp, "hamilton", trending = TRUE, lags = 1)
#> Specification strategy: Hamilton (rule-based)
#> 
#>   Lags: 1 (fixed)
#>   Sample (all regressions): N = 262 (t = 3, ..., 264)   Level: 5%
#> 
#>   Step Regr.  Test       Statistic Crit.val.  p-value  Decision    Next
#>   1    ct     tau3          -1.489    -3.427    0.831  not reject  stop
#> 
#>   Specification: constant and linear trend
#>   Conclusion:    unit root (with drift)
#> 
#>   Note: p-values are for each step on its own (none for the phi tables);
#>   no p-value or size is reported for the sequence as a whole.

There is no default for trending: the choice is yours, and the result says so. summary() on any strategy shows each step with its null hypothesis, the critical value and its source, and the reason for the next step. Note that the history separates rejections of the unit root from rejections that only decide the path (the ϕ\phi tests and the tests of the deterministic terms).

Each step has its own p-value (there is none for the ϕ\phi tests, whose critical values come from tables). These p-values describe each test on its own. The procedure as a whole has no known size: it is a sequence of tests, each conditional on the results of the previous ones, so no p-value is given for it.

4. Other tests

The Phillips-Perron test corrects for serial correlation non-parametrically instead of adding lagged differences; DF-GLS detrends by GLS, which improves power; and the KPSS test reverses the null hypothesis: it tests stationarity against a unit root.

#> Phillips-Perron test (Z_tau)
#> 
#>   H0: unit root
#>   H1: stationary around a linear trend
#>   Deterministics: constant and linear trend
#>   Bandwidth: 5 (short: trunc(4 ((T-1)/100)^(1/4)))
#>   Effective sample: N = 263 (t = 2, ..., 264)
#> 
#>   Statistic:        -1.111
#>   Critical values:  1%: -3.994   5%: -3.427   10%: -3.137
#>   Source:           MacKinnon (2010) response surface
#>   p-value:          0.924
#> 
#>   Decision at 5%: do not reject H0 (unit root)

#>   H1: unit root

#>   Statistic:        0.701
#>   Critical values:  1%: 0.216   2.5%: 0.176   5%: 0.146   10%: 0.119
#>   Source:           Kwiatkowski et al. (1992), Table 1
#> 
#>   Decision at 5%: reject H0 (stationary around a linear trend)

Two details of dfgls(). Without lags, the number of lagged differences is chosen as recommended by Perron and Qu (2007): by MAIC, exactly as for adf(), on the series detrended by ordinary least squares; the DF-GLS statistic is then computed with that number of lags. And its critical values and p-value come from this package’s own simulations: in samples of usual size the DF-GLS statistic has a heavier left tail than its limit distribution, and the asymptotic critical values used by other software reject a true unit root too often (about 8% of the time at the 5% level with T=100T = 100 and a constant).

A non-rejection is not evidence for the null. Using tests with both nulls is one way to see how strong the evidence is in each direction.

5. Collecting results in a table

glance() turns a test into one row of a data frame and tidy() gives one row per statistic, so results are easy to compare or to save. For example, the four tests on log GDP with constant and trend:

tests <- list(adf(lgdp, trend = "ct"), pp(lgdp, trend = "ct"),
              dfgls(lgdp, trend = "ct"), kpss(lgdp, trend = "ct"))
res <- do.call(rbind, lapply(tests, glance))
res[, c("test", "statistic_name", "statistic", "p_value", "reject", "lags", "nobs")]
#>     test statistic_name  statistic   p_value reject lags nobs
#> 1    ADF           tau3 -1.4891169 0.8311624  FALSE    1  262
#> 2     PP          Z_tau -1.1105222 0.9243191  FALSE    5  263
#> 3 DF-GLS        tau_GLS -1.0192578 0.8624955  FALSE    1  262
#> 4   KPSS        eta_tau  0.7007647        NA   TRUE    5  264

tidy() shows the accompanying statistics as well, for instance the ϕ\phi statistics of the ADF test:

tidy(adf(lgdp, trend = "ct"))[, c("statistic_name", "statistic", "critical_value", "p_value", "reject")]
#>   statistic_name statistic critical_value   p_value reject

#> 2           phi2 17.611863       4.750000        NA   TRUE

The same functions work on a strategy: glance() gives its outcome in one row and tidy() its history.

6. Why special critical values?

Under the unit-root null, the t ratio of bb does not have a normal or Student t distribution. simulate_df() shows this by simulation:

s <- simulate_df(T = 100, R = 2000, trend = "c", seed = 1)
s
#> Simulated Dickey-Fuller distribution of tau2
#> 
#>   Data: driftless random walk, T = 100 (N = 99); R = 2000 replications
#>   Test regression: constant
#> 
#>   Level   Simulated  MacKinnon (resp.)     N(0,1)
#>   1%         -3.459             -3.498     -2.326
#>   5%         -2.889             -2.891     -1.645
#>   10%        -2.556             -2.583     -1.282
#> 
#>   Share of simulated tau below the normal 5% quantile: 0.460
#>   (a correctly sized test would reject 0.050 +/- 0.010)
plot(s)

The simulated quantiles agree with MacKinnon’s critical values, which are far to the left of the normal ones. Using the normal 5% value would reject a true unit root much more often than 5% of the time.

7. Data formats

The functions accept numeric vectors, ts, zoo and xts series, data frames, tibbles and tsibbles. When there are several numeric columns, name the one to test with var:

df <- data.frame(date = as.Date(gdp$date), lgdp = log(gdp$rgdp),
                 growth = c(NA, diff(log(gdp$rgdp))))
adf(df, var = "lgdp", trend = "ct", lags = 1)$statistic
#> [1] -1.489117

Missing values are never dropped silently: the growth column above starts with NA, and testing it gives an error that says where the problem is.
